```python
# cinesort/infra/probe/ffprobe_backend.py:38-41
```

`subprocess.TimeoutExpired` n'est PAS dans la liste. `TimeoutError` est la version
asyncio/PEP418 generique, pas l'exception du subprocess. Verdict : tout depassement
de `probe_timeout_s` casse l'appel jusqu'au sommet (REST handler). Idem dans
`mediainfo_backend.py:22`.

`probe_files` parallel (`service.py:472`) intercepte `OSError, RuntimeError,
TypeError, ValueError` mais pas non plus `TimeoutExpired`. Sur scan batch >1, un
seul fichier en timeout casse le `as_completed` cumulatif.

### Conclusion section 2

CASSE CONFIRMEE oui (sur scenario a + indirectement c via meme mecanisme).
Trois symptomes documentes :

1. **Score invente / ligne disparue trompeur** : sans probe (echec subprocess
   silencieux), `compute_quality_score` retombe sur `_merge_probe_with_name_hints`
   (fallback nom de release) et produit un score Reject 23-28 derive du nom
   de fichier sans aucune mesure reelle. Pour l'utilisateur, le film est
   "qualifie" alors qu'aucune metadata video/audio n'a ete lue.
   -> Memoire violee : "PAS score invente PAS ligne disparue PAS 0 trompeur".

2. **Endpoint `quality/get_quality_report` casse en cascade** : la
   `TimeoutExpired` n'est pas attrapee dans `ffprobe_backend.run_ffprobe_json` ni
   `mediainfo_backend.run_mediainfo_json`. Elle traverse jusqu'au REST handler
   qui repond 200 + `ok=false`, payload `score/tier/probe_quality` vides.
   Le frontend voit un succes HTTP mais une reponse incomplete -> degradation
   silencieuse (couleur tier perdue, pas d'erreur user-facing).

3. **Polling UI sans backoff sur degradation** : pendant qu'un probe hang
   ~35s, l'UI continue de poller toutes les 2-5s. Sur 9 films, c'est
   ~5min de hang pendant lequel le serveur empile des requetes get_status
   qui ne chevauchent pas le probe (different endpoint) mais cumulent
   les hangs pour chaque demande `quality_report` cliquee.

4. **Aucun retry/backoff cote `tooling.py`** : `default_runner` appelle
   `tracked_run` une fois, propage `TimeoutExpired`. Pas de circuit-breaker,
   pas de marquage `tool_unavailable` durable -> chaque film paie 30s.
