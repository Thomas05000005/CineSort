### Mega-hotfix (2026-06-04, recap)

Tag `mega-hotfix` consolidant 17 correctifs sur 5 rounds (R1, R2, R3, R4,
ultra) :

- Data integrity : `apply_rollback` swap atomique + fsync, journal hash
  SHA-256, compteur `applied_count`
- Securite : `redact_secrets` sur logs, settings DPAPI sans BOM,
  suppression fallback token en clair
- Parallelism : semaphore relachement sur exception, timeout global
  futures, lock sur compteur progression
- Scoring : `composite_score` deterministe (tri secondaire `file_path`),
  `audio_fingerprint` recalibrage
- Windows paths : prefixage `\\?\` homogene, normalisation separateurs
- Audio fingerprint : offset 1 frame corrige, cache par hash
- Custom rules : validation regex stricte, sandbox 50ms ReDoS, multi-lignes
- apply_core : deplacements croises, arrondi tailles, trace `apply_id`
- Backward compat : migration 0007 -> 0008 ALTER TABLE manquant
- UI polish : focus modale "Annuler", flicker tableau scoring, tooltips
  panneau Avance, scroll position
