### Findings nouveaux (HIGH / MED)

1. **bug(infra-notifications) sev 2** — `_encode_wstr` tronque par code points
   Python plutot que par code units UTF-16. Pour un titre de notification
   contenant des emojis (noms de films comme "🎬 Cyberpunk 2077"), le buffer
   encode UTF-16-LE peut depasser `max_chars * 2` octets et `struct.pack`
   tronque silencieusement au milieu d'une surrogate pair. Resultat : glyphe
   de remplacement dans le centre de notifications Windows.
   -> Issue #536, PR #537 (FIX + 6 tests Hypothesis-style sur les surrogates).

2. **orphan(jellyfin-sync) sev 2** — `restore_watched` capture
   `play_count` + `last_played_date` dans `WatchedInfo` mais n'appelle que
   `mark_played` (binaire). Apres apply, un film vu 17 fois retombe a 1
   visionnage et `last_played_date` est ecrase par le moment du restore.
   2 champs de la dataclass sont des donnees orphelines (code mort) et
   l'utilisateur perd silencieusement son historique de visionnage.
   -> Issue #535.
