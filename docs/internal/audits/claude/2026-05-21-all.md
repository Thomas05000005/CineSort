## Par module

### cinesort/app/omdb_cross_check.py

- `_normalize_title_for_compare` (L41-55) : `re.sub(r"[^a-z0-9]", "", s)` recompile
  la regex a chaque appel. Imports `re`, `unicodedata` lazy dans la fonction.
- **Severite** : STYLE (1)
- **Fix** : pre-compiler `_ALPHANUM_STRIP_RE` au niveau module, imports top-level.
- **Action** : PR #323 (perf(omdb-cross-check)).

### cinesort/app/apply_core.py + cinesort/ui/api/diagnostics_support.py

- `unique_path` (L226), `unique_path_dup` (L240), `diagnostics_support.unique_path` (L105) :
  `while True` sans cap. Risque busy-loop si FS verrouille ou collisions adversariales.
- **Severite** : QUALITY (2)
- **CWE** : CWE-835 Infinite Loop
- **Fix** : cap `_UNIQUE_PATH_MAX_ATTEMPTS = 10_000` + fallback timestamp ns.
- **Action** : PR #324 (fix(unique-path)).

### cinesort/domain/explain_score.py

- `_compute_category_contribution` (L85) : `total = max(1, ...)` clamp les poids
  a 1 si tous les poids sont 0 -> retourne weight_pct calcule sur sentinel.
- **Severite** : QUALITY (2)
- **Fix** : branche explicite `if sum_weights <= 0: return {weight_pct: 0.0, ...}`.
- **Action** : PR #325 (fix(explain-score)).

### cinesort/app/move_journal.py + cinesort/app/move_reconciliation.py

- `journaled_move` (L78) : `except Exception` apres echec `insert_pending_move`
  -> swallow silencieux, continue le move sans journal write-ahead.
- `reconcile_pending_moves` (L86) : `except Exception` au boot, retourne report
  vide. User croit que reconcile a marche, orphelins persistent.
- **Severite** : QUALITY (2)
- **CWE** : CWE-391 Unchecked Error Condition
- **Fix** : catcher specifiquement `sqlite3.OperationalError`, propager les autres.
- **Action** : Issue #326.

### cinesort/domain/calibration.py

- `_rebalance_weights` (L170-192) : retourne None silencieusement quand l'invariant
  somme=100 ne tient pas. Pas de log debug pour tracer.
- **Severite** : STYLE (1) / observability
- **Fix** : `logger.debug` ligne 192 si `diff != 0`.
- **Action** : Issue #327.

### cinesort/infra/jellyfin_client.py

- `mark_unplayed` (L471) : appelle directement `self._session.delete(url, timeout)`
  sans wrapper alors que `_get`/`_post` convertissent `requests.RequestException`
  en `JellyfinError`. Asymetrie d'error handling.
- **Severite** : STYLE (1)
- **CWE** : CWE-754 Improper Exception Handling
- **Fix** : ajouter `_delete()` symetrique et utiliser dans `mark_unplayed`.
- **Action** : Issue #328.
