### Categorie 1 — Bug logique (1 BUG)

**#749 (ouverte) / PR #750** — Faux doublon de langue sur paire VobSub.

`cinesort/domain/subtitle_helpers.py:314` — la boucle de decompte des doublons :

```python
for s in matched:
    if s.language:                       # AVANT : compte .idx ET .sub
        lang_counts[s.language] = lang_counts.get(s.language, 0) + 1
```

Une paire VobSub `Movie.fr.idx` + `Movie.fr.sub` (`SUBTITLE_EXTS` inclut les deux) compte donc **2× FR** → faux `duplicate_languages=['fr']`.

Fix (1 LOC + commentaire WHY) :

```python
for s in matched:
    if s.language and s.ext != ".idx":   # APRES : le .idx accompagne toujours son .sub
        lang_counts[s.language] = lang_counts.get(s.language, 0) + 1
```

Le `.idx` reste present dans `count`, `formats`, `languages` — seul le decompte des doublons l'exclut. Un **vrai** second sous-titre FR (ex: `Movie.french.srt` a cote de la paire) reste correctement signale. Deux tests ajoutes (`test_vobsub_pair_not_flagged_as_duplicate`, `test_vobsub_plus_srt_same_lang_is_real_duplicate`) ; suite `test_subtitle_helpers` → 33 OK.
