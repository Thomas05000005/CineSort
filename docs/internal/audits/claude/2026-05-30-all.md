## Résumé exécutif

Le codebase est dans un état très propre après 18 jours d'audit continu (issues #75 → #480). Les
findings nouveaux à haute confiance sont peu nombreux et tous de sévérité 1-3 (aucun BLOCKER).

**Top 5 findings de ce run** :

1. **Atomicité des écritures `plan.jsonl` + export CSV** (#479, sev 3, R1) — `_save_plan_artifacts`,
   `export_library` (CSV), `start_demo_mode` écrivent sans pattern tempfile+rename. Le NDJSON juste à
   côté le fait, donc c'est une incohérence corrigeable.
2. **Logger.error sans exc_info → perte traceback** (PR #476, sev 2, L1) — 4 sites (export_full_library,
   auto_install_probe_tools, install ffprobe/MediaInfo, rollback_migration) convertis en
   `logger.exception` pour préserver le traceback complet en logs.
3. **`_in_list` allouait une liste temporaire par appel** (PR #477, sev 2, P1) — hot path filtrage
   bibliothèque, remplacé par set comprehension. Bonus : `_normalize_codec` dédupliqué.
4. **`sorted(...)[0]` → `min(...)` dans `find_best_nfo_for_video`** (PR #478, sev 1, P2) —
   2 sites, O(n) vs O(n log n), appelé 2× par film lors d'un apply.
5. **`@lru_cache` manquant sur `normalize_title_for_ambiguity`** (#480, sev 1, P3) — fonction pure
   appelée 2500-50000× par scan, beaucoup de répétitions sur les franchises.
