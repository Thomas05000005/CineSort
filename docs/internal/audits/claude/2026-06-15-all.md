### 14 - ERROR_HANDLING

**Findings nouveaux : 1**

#### Finding A1 — port SMTP non-numerique crashe thread daemon

`cinesort/app/email_report.py:91` :

```python
host = str(settings.get("email_smtp_host") or "").strip()
port = int(settings.get("email_smtp_port") or 587)  # ← hors try/except
user = str(settings.get("email_smtp_user") or "").strip()
```

La conversion `int()` est realisee hors du try/except (qui commence ligne 111).
Si l'utilisateur saisit un port non-numerique dans les settings (`"abc"`,
`"587 "`...), ValueError remonte dans le thread daemon `dispatch_email`
qui meurt silencieusement. Aucun log, aucune notification UI : l'utilisateur
croit que les emails sont envoyes alors que rien ne part.

Fix : helper `_resolve_smtp_port()` symetrique a `_resolve_smtp_timeout()`.

- Issue : #590
- PR : #591
