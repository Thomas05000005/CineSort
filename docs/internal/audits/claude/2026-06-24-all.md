## Findings detailles

### PR #658 — composite_score_v2 `_score_audio_spectral` : verdicts mal compares
`classify_cutoff` (spectral_analysis.py) emet `lossy_high`/`lossy_mid`/`lossy_low`, mais `_score_audio_spectral` comparait a `high_bitrate_lossy`/`medium_bitrate_lossy`/`low_bitrate_lossy`. Aucune branche lossy ne matchait : fallback `60.0, conf 0.0` systematique, sous-score audio spectral inerte (tous les lossy notes pareil). Corrige + 4 tests (mid/high/native_nyquist), 64 tests OK.

### PR #659 — composite_score_v2 `_score_hdr` : sentinelle 0.0 vs None
`max_cll`/`max_fall` sont normalises a `0.0` (pas `None`) en amont. Le garde `if has_hdr10 and (max_cll is None or max_fall is None)` ne se declenchait jamais -> flag « HDR10 incomplet » mort. Corrige en testant la valeur falsy + test `test_hdr10_with_zero_maxcll_flag`, 62 tests OK.

### #660 — mel_analysis `detect_aac_holes` : plancher dB == seuil de trou
`mel_to_db` clippe a `[-80, 0]` (`top_db=80`). `band_means >= -80` toujours, donc `band_means < MEL_AAC_HOLE_THRESHOLD_DB` (-80.0) impossible -> `hole_ratio=0`, verdict fige a `normal`. Detection AAC bas bitrate morte (faux negatifs). Consomme via `audio_perceptual.mel_aac_holes_ratio`, `models.py`.

### #661 — apply_core `apply_collection_item` : MAX_PATH sidecars non verifies
Le killswitch MAX_PATH ne teste que la video (`sub_dir/video`), pas les sidecars (`sub_dir/sidecar.name`, l2241). `apply_tv_episode` GATE 3 verifie video+sidecars. Asymetrie -> sous Windows, item collection a moitie applique si un sidecar a nom long depasse alors que la video passe.

### #662 — librarian `generate_suggestions` : health_score negatif possible
`problem_ids` melange row_id de `rows` (B/C/D/F) et de `quality_reports` (A codec, E low_res), mais `total_rows = len(rows)`. Un quality_report orphelin (replan) gonfle `problem_ids` sans gonfler `total_rows` -> `healthy < 0` -> score hors borne. Fix : intersection avec les ids valides de `rows`.

### #663 — tests/test_librarian.py : skip module entier
`raise unittest.SkipTest` au niveau module (garde frontend legacy `web/index.html`) skippe 8 classes **domaine** sans rapport avec le front. `librarian.py` non couvert en CI ; bloque l'ajout du test de #662. Fix : limiter le skip a `UiSuggestionsTests` (deja `@unittest.skip`).

### #664 — profile_exchange `extract_import_metadata` : json.loads sans garde taille
Preview d'import (entree non fiable) parse sans `MAX_JSON_BYTES`, alors que `parse_and_validate_import` rejette en amont. DoS local possible (CWE-400). Fix : meme garde en tete, retour dict vide.
