## Par module (detail)

### Domain + perceptual

#### `cinesort/domain/perceptual/composite_score_v2.py:619`
- **Sev 3** / cat 17+2 / conf 0.92 / Persona DB+RELIABILITY
- `collect_warnings` lit `duration_s` depuis `video_data["duration_s"]` (sous-dict probe `video`) qui ne contient JAMAIS cette cle. Le champ est au top-level de `NormalizedProbe`. Resultat : warning runtime mismatch affiche toujours "Duree fichier 0 min".
- Fix : `(normalized_probe or {}).get("duration_s", 0)` au lieu de `video_data.get("duration_s", 0)`.
- **Issue #505 / PR #528**

#### `cinesort/domain/quality_score.py:119, 152`
- **Sev 3** / cat 2+11 / conf 0.90 / Persona DB
- Presets `remux_strict` et `light` (et `equilibre` mais par chance OK) font `update({"premium": ...})` qui n'ecrase pas le `platinum` deja present dans base. `validate_quality_profile` lit `tiers.get("platinum", tiers.get("premium"))` -> les valeurs voulues sont ignorees.
- Fix : utiliser les noms canoniques v7.2.0+ (platinum/gold/silver/bronze).
- **Issue #506 / PR #529**

#### `cinesort/domain/perceptual/parallelism.py:114, 136, 230, 251`
- **Sev 3** / cat 14+1 / conf 0.85 / Persona RELIABILITY
- `subprocess.TimeoutExpired` herite de `SubprocessError`, pas de `RuntimeError`. Les pools ne le catch pas.
- Fix : ajouter `subprocess.SubprocessError` au tuple.
- **Issue #507 / PR #530**

#### 5 callers `ffmpeg_runner` sans wrapper try/except
- **Sev 3** / cat 14 / conf 0.85 / Persona RELIABILITY
- audio_perceptual.{analyze_loudnorm, analyze_astats, analyze_clipping_segments}, video_analysis.run_filter_graph, frame_extraction.extract_single_frame.
- Combine avec parallelism : un timeout = batch entier plante.
- **Issue #508**

#### `cinesort/domain/perceptual/audio_perceptual.py:583-629`
- **Sev 2** / cat 2+11 / conf 0.80
- `_compute_audio_score` : la branche TP clipping (loud) decremente `s_clip` de 40, puis la branche deep clipping (clip) reaffecte `s_clip` complet -> evidence TP ecrasee.
- **Issue #523**

#### `cinesort/domain/perceptual/audio_fingerprint.py:99-110`
- **Sev 1** / cat 11+2 / conf 0.80
