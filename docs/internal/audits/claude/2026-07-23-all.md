## Par module

### cinesort/app/disk_space_check.py:56 — `_row_estimated_size`
- Sévérité : **high** (BUG, cat. 2, RELIABILITY)
- Une collection (`row.video` vide) est sommée via `folder.iterdir()` (fichiers immédiats)
  alors que `merge_dir_safe` déplace `src_dir.rglob("*")` récursivement.
- Fix : `iterdir()` → `rglob("*")`. **Corrigé dans PR #799** (+ test).

### cinesort/infra/radarr_client.py:147 (+ omdb, tmdb) — cap de taille `.content`
- Sévérité : **high** (SEC, cat. 4, CWE-400)
- `getattr(resp,"content",b"")` matérialise tout le body avant le test `len > 10 Mo`.
- Fix : lecture streaming bornée (`resp.raw.read(MAX+1)`), factorisée dans `_http_utils`.

### cinesort/infra/network_utils.py:59 — `is_safe_external_url`
- Sévérité : **high** (SEC, cat. 4, CWE-918)
- Formes IP décimale/octale/hex → `ValueError` → classées FQDN → autorisées vers metadata.
- Fix : résoudre `getaddrinfo` et valider toutes les IP contre les blocs interdits.

### cinesort/domain/quality_score.py:534 — `_normalize_video_bitrate_kbps`
- Sévérité : **medium** (QUALITY, cat. 2)
- Invariant probe = bps (`to_optional_bitrate`, `_to_bitrate_int`) ; la fonction vidéo ne
  divise que si `n>500000`, contredisant la fonction audio (division inconditionnelle R8-038).
- Fix : division inconditionnelle. `needs-review` (scoring central, tests à valider).

### cinesort/ui/api/quality_simulator_support.py:281 — `_apply_weights`
- Sévérité : **medium** (QUALITY, cat. 2)
- `int(weights.get("video") or 0)` tronque un poids fraction (0.6→0) → `score_after`=0.
- Fix : `float()` pour les poids. À traiter avec la remise en service du simulateur (#729).
