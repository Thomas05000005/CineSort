## Par module

### cinesort/infra/state.py:87 — PR #831 (Closes #820)

- `atomic_write_json` ecrivait le tmp via `tmp.write_text(...)` puis `os.replace` sans
  `fsync` prealable. Sur crash/coupure entre le write et le flush OS, le rename atomique
  peut pointer vers un contenu tronque (le rename est atomique, PAS le contenu).
- Fix : `open(...,'w')` + `f.flush()` + `os.fsync(f.fileno())` avant `os.replace`.
- **Severite** : RELIABILITY (3) — **CWE-662** durabilite. **Conf** 0.90.

### cinesort/infra/network_utils.py:60 — PR #832 (Closes #733)

- `is_safe_external_url` ne bloquait que le bloc IPv4 `169.254.0.0/16` en dur. Les
  adresses IPv6 link-local (`fe80::/10`) et IPv4-mapped (`::ffff:169.254.169.254`)
  contournaient le filtre SSRF cloud-metadata.
- Fix : parse `ipaddress.ip_address`, deplie `ipv4_mapped`, teste `ip.is_link_local`.
- Dedup : recoupe l'issue OPEN **#733** (link-local IPv6) — la PR la ferme plutot que
  d'ouvrir un doublon (CAS B/D).
- **Severite** : SECURITY (3) — **CWE-918** SSRF. **Conf** 0.88.

### cinesort/infra/integrations/poster_proxy.py:113 — PR #833 (Closes #821)

- `except (ImportError, SecretStorageError, Exception) as exc:  # noqa: BLE001` :
  le `Exception` rend les deux premiers types redondants et avale toute erreur en
  `logger.debug` (invisible en prod). **CWE-396**.
- Fix : `except (ImportError, SecretStorageError)` + `logger.warning(type(exc).__name__)`.
- **Severite** : STYLE (2). **Conf** 0.85.

### cinesort/app/export_support.py:280 — PR #834 (Closes #822)

- `export_nfo_for_run` ecrivait chaque `.nfo` via `nfo_path.write_text(...)` (troncature
  destination avant reecriture). Coupure I/O => `.nfo` partiel lu par Kodi/Jellyfin.
- Fix : tmp + `fsync` + `os.replace`, cleanup best-effort du tmp. Ajout `import os`.
- **Severite** : RELIABILITY (3) — **CWE-662**. **Conf** 0.88.

### cinesort/domain/perceptual/upscale_detection.py:111 — Issue #823

- `is_frame_usable_for_fft` teste une garde de variance sur une cle jamais peuplee
  (dict `frame_stats` ne recoit jamais `variance`) => la garde est morte, les frames
  plates ne sont jamais filtrees avant la FFT (faux positifs upscale).
- **Severite** : BUG (3). **Conf** 0.80. Fix non-trivial (peupler la cle ou retirer la
  garde) => issue.
