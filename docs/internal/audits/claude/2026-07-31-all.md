## Par module (finding retenu)

### cinesort/domain/perceptual/parallelism.py
- **sévérité** : bug (3) · **catégorie** : 14 (error handling) + 5 (concurrence)
- **fichier:ligne** : `parallelism.py:107` (`run_parallel_tasks`)
- **description** : le fast-path `if workers <= 1 or len(tasks) == 1:` exécute `fn()` sans
  appliquer `timeout_per_task_s`. Deux appelants réels passent un timeout avec une seule
  tâche (`perceptual_support.py:445`, une détection méta activée) ou avec `max_workers=1`
  (`perceptual_support.py:503` sur machine 2-3 cœurs). Le garde-fou anti-hang ffmpeg est
  alors désactivé → analyse perceptuelle qui peut bloquer indéfiniment.
- **fix** : `if timeout_per_task_s is None and (workers <= 1 or len(tasks) == 1):` — avec
  timeout, on route via le `ThreadPoolExecutor` (1 worker suffit) qui borne l'exécution.
- **action** : issue #836, PR #837 (+ 3 tests de régression).
