## Par module

### cinesort/ui/api/cinesort_api.py:1206-1208

- **severite** : 2 (BUG)
- **categorie** : 2 (BUG_DOMAINE — sentinel value confusion)
- **persona** : RELIABILITY
- **description** : `_get_jellyfin_sync_report_impl` lit `info["user_id"]` sans verifier
  `info["ok"]`. En cas d'echec d'auth, l'appel `get_all_movies_from_all_libraries("")`
  partait avec une chaine vide, masquant la cause reelle de l'erreur.
- **fix** : Ajouter check `if not info.get("ok") or not info.get("user_id"): return _err_response(...)`.
- **PR** : #572 (Closes #464).

### cinesort/infra/db/backup.py:243-247

- **severite** : 2 (QUALITY)
- **categorie** : 9 (MIGRATIONS_DB)
- **persona** : DB
- **description** : `restore_backup` ouvre la cible sans purger `target-wal` / `target-shm`
  residuels. Le WAL orphelin peut etre rejoue par-dessus le contenu restaure, ou laisser
  un `-wal` incoherent. Cas typique : auto-restore post-corruption.
- **fix** : `unlink(missing_ok=True)` sur les deux sidecars avant `sqlite3.connect(target).backup(...)`.
- **PR** : #573 (Closes #468).
