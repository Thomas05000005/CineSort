  concluait à un collapse du throttle sous concurrence ; **vérification faite**, quand la
  réservation `_last_request_ts` est dans le futur, `elapsed = now - T` devient négatif donc

  **s'empilent correctement**. Rate limiter correct → discard (FILTRE 1/7).
