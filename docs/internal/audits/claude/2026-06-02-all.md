## Résumé exécutif

Une seule trouvaille critique d'un coup, mais avec un impact massif : **6 sites du code prod construisent `state_dir/runs/{run_id}/plan.jsonl`** alors que la convention établie (state.new_run, runtime_support.run_paths_for, job_runner) est `state_dir/runs/tri_films_{run_id}/`. Les 6 fonctions concernées retournaient silencieusement *Aucun film dans ce run.* en production, cassant les rapports Jellyfin/Plex/Radarr, l'import watchlist et l'historique des films, **sans aucun signal dans les logs ni dans l'UI**.

Cause racine de l'invisibilité : la suite de tests dédiée (`test_film_history`) est entièrement skip depuis PR #257 (legacy frontend supprimé), et les autres tests d'intégration (`test_cinesort_api_email/plex/radarr/plugins`) reproduisaient la même erreur dans leur fixture (`state_dir/runs/run1/plan.jsonl`), faisant donc passer le test alors que la prod cassait.

Issue #502 ouverte, PR #503 (fix + ajustement de 5 fixtures de tests) ouverte sur `main`.
