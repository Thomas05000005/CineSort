## Resume executif

2. **Perf** dans `omdb_cross_check.py:54` : regex `r"[^a-z0-9]"` recompilee + imports `re`/`unicodedata` dans le corps de fonction appelee sur des milliers de rows. **Fix livre dans PR #285.**

3. **CWE-425** dans `_http_utils.py:15` : `POST` inclus dans `DEFAULT_RETRY_METHODS`, viole RFC 7231 idempotence. Doublons possibles en production sur retries (mark_played, refresh library). **Issue #286.**

4. **CWE-835** dans `backup.py:155` : `while True` sans borne dans `_compute_backup_path`. FS read-only / NAS bavard -> blocage de tous les apply. **Issue #287.**

5. **CWE-252** dans `jellyfin_sync.py:221` : `restore_watched` n'a pas de guard sur `client is None` / `mark_played` absent ; retour `None` traite comme `True`. **Issue #289.**
