## Detail des findings

### 1. sqlite_store.py:64 — `_detect_cloud_sync_folder` match sous-chaine

- La docstring (l.54-57) promet explicitement une comparaison **segment par segment**
  pour eviter les faux positifs ; le code fait `marker.lower() in path_str` sur le
  chemin entier. Le code fait exactement ce que la docstring dit d'eviter.
- Faux positifs : `/.../Boxing/...` -> `Box`, `/.../MegaMovies/...` -> `Mega`,
  `D:\Sandbox\...` -> `Box`. Declenche a tort l'avertissement « DB sur dossier cloud ».
- **Severite** : 2 (BUG) - **CWE-697** Incorrect Comparison.
- **Fix** : `Path(...).parts` + dict `markers_lower`, couvre aussi « Google Drive ».
- **Action** : Issue #685, PR #687.

### 2. log_context.py:198 — fuite memoire du dedup d'exceptions

- `RepeatedExceptionDedupFilter.filter()` purge le **contenu** des listes de timestamps
  (fenetre 60 s) mais jamais les **cles** de `self._counts`. Chaque combinaison unique
  `(logger, type, msg[:80])` reste a vie.
- Filtre installe au boot sur le root logger + handlers -> croissance monotone sur
  process long (watcher/daemon notify). `msg[:80]` contient souvent des fragments
  variables -> cardinal des cles non borne.
- **Severite** : 2 (BUG) - **CWE-401** Missing Release of Memory.
- **Fix** : balayage opportuniste des cles a liste vide au-dela d'un cap souple (512).
- **Action** : Issue #684, PR #688.

### 3. plan_support_dedup.py:764 — comptage cross-root + non-determinisme

- `dup_count += 1` par row flaggee alors que le caller logge « N film(s) » -> total
  gonfle (x2+ selon le nombre de roots par film).
- `roots_seen` est un `set` -> ordre des roots dans `row.notes` (« Aussi dans: … »)
  non deterministe -> sortie non reproductible.
- **Severite** : 1 (STYLE/QUALITY).
- **Fix** : compter une fois par film (par groupe) + `sorted(roots_seen)`.
- **Action** : Issue #686, PR #689.

### 4. merge_metadata.py:109 — sous-cas bool/False (enrichit #638)

- `isinstance(value, (int, float)) and value == 0` capture aussi les **booleens**
  (`bool` est sous-classe d'`int`, `False == 0`). Un flag `target` legitimement `False`
  (ex. `has_subtitles=False`) est traite comme « manquant » et ecrase en mode
  « completer les manques ».
- Meme racine que #638 (qui traite le `0`/`0.0` numerique) : sous-cas distinct ajoute
  en commentaire sur #638 plutot qu'en issue dupliquee.
- **Severite** : 2 (BUG) - **CWE-704** Incorrect Type Conversion.
- **Action** : commentaire d'enrichissement sur #638.
