## Findings par persona

### A0 — Bloquant (1 finding, 1 PR)

1. **#646 / PR #647 — `cinesort.domain._fuzzy_normalize` manquant.** `git ls-files` ne liste pas le fichier ; `grep -rn "def normalize_for_fuzzy"` -> 0. Importeurs top-level : `_fuzzy_utils.py:15`, `duplicate_multi_signal.py:28`. Cause : le squash R8 (`650d162`) a deplace la fonction de `app._fuzzy_utils` vers `domain._fuzzy_normalize` (imports mis a jour) sans creer le fichier cible. Fonction recuperee a l'identique depuis `bda2b67:cinesort/app/_fuzzy_utils.py` (string pure, stdlib `unicodedata`). **Confiance 100 %** (verifiable par import).

### A1 — Performance & sentinelles (couche app, 2 findings, 0 PR)

2. **#637 — `folder_signature` fait 3 `stat()` par video** alors que `entry.stat()` (DirEntry du `os.scandir`) est deja disponible. Surcout I/O notable sur gros volumes / NAS. Bug perf, fix non-trivial (refactor de signature) -> issue.
3. **#638 — `_is_empty` traite `0`/`0.0` comme vide** dans `merge_metadata`. En mode `replace_data=False` (« completer les manques »), une valeur source `0` legitime ecrase une valeur cible existante. Sentinelle `0` vs absent. Bug comportemental -> issue (changement de semantique a arbitrer).

### A2 — Calibration (couche domain, 1 finding, 0 PR)

4. **#639 — `suggest_weight_adjustment` ressuscite un poids `0`.** `int(current_weights.get("video", 60) or 60)` : un poids volontairement mis a `0` est traite comme falsy et remplace par le defaut 60/30/10. Bug `0`-vs-None -> issue.

### A3 — Integrite (couche domain, 1 finding, 0 PR)

5. **#640 — Faux positif « tronque » sur MKV.** Un MKV se terminant par des octets nuls (padding void EBML legitime) est flague tronque par l'heuristique tail-nulls. Bug d'integrite -> issue.

### A4 — Encode (couche domain, 1 finding, 0 PR)

6. **#641 — `analyze_encode_quality` classe par `height` seule.** Un 720p cinemascope (1280x536) est traite en SD, en desync avec `_resolution_label` (width-first). Incoherence inter-modules -> issue.

### A5 — Securite (couche infra, 1 finding, 1 PR)

7. **#642 / PR #643 — `validate_key` renvoie `r.text[:200]` non scrub.** Le corps de reponse HTTP TMDb (qui peut contenir des echos de la cle API) etait insere brut dans le message UI. CWE-532 (Information Exposure Through Log/Message). Fix : passer par `scrub_secrets()` (deja present dans `log_scrubber.py`). **Confiance 90 %**.

### A6 — Proprete & lint (transverse, 3 findings, 3 PRs)

8. **#644 / PR #645 — Constante morte `_EXPORT_FIELDS`** dans `library_actions_support.py` (0 reference). Suppression sans risque.
9. **#648 / PR #649 — `except ImportError` mort** autour de `_adj_th` dans `quality_score.py` : `_adj_th` est importe top-level (L24), l'except interne ne peut jamais se declencher.
10. **#650 / PR #651 — `Optional` reference sans import** dans `state.py` (`atomic_write_json`). Pas de crash runtime grace a `from __future__ import annotations`, mais nom non defini (F821).
