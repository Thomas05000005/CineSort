Le repo est déjà très audité (audits quotidiens jusqu'au 2026-05-27). L'audit du jour cible donc du **nouveau** après dédup stricte contre les issues #423-435 et PRs #436-439 récentes. 14 findings nouveaux confirmés par lecture du code réel, dont **3 sévérité 3 (BUG)** :

**Thème dominant** : *features écrites mais jamais activées* (toggle `include_subtitles` mort, mirror insights→notifications mort, tolérance vintage sur ères inexistantes, diagnostic sur table inexistante, simulateur cassé). Le backend calcule, l'UI ne reçoit rien — pattern « orphan » récurrent.
