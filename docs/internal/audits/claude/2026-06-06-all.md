### Top findings

1. **sec(infra-tmdb,omdb)** [#539, PR #546] - `_load_cache` / `_cache_get_stale` chargent `cache_path.read_text()` sans cap de taille. Cache corrompu ou backup invalide -> OOM au boot. Fix : cap 100 MB (TMDb) / 50 MB (OMDb) avant `read_text()`.
2. **rel(infra-omdb)** [#540, PR #546] - `_save_cache_atomic` OMDb sans `os.fsync` entre `write_text` et `replace` -> cache tronque au crash. Symetrique avec PR #531 (atomic_write_json fsync). Fix : `flush()` + `os.fsync()`.
3. **bug(app-runtime-probe)** [#541, PR #547] - `float(duration_s)` sans try/except si backend probe renvoie "N/A" -> ValueError termine le scan runtime entier. Fix : try/except local + cache `duration_min`.
4. **perf(app-omdb-cross-check)** [#542, PR #548] - `_normalize_title_for_compare` (3 re.sub + 2 unicodedata.normalize) sans memoization, appele dans une hot loop. Fix : `@lru_cache(2048)`.
5. **rel(app-notify-service)** [#543] - `shutdown()` / `_drain_tick()` muent `_drain_active` et `_drain_timer` sans lock -> timer zombi possible. Fix propose mais non execute en PR (race fenetre etroite, daemon=True attenue l'impact).
6. **bug(app-jellyfin-validation)** [#544] - matching dossier par prefix containment retient le 1er candidat sans verifier le nom de fichier -> faux match sur dossiers freres (editions multiples, sagas).
7. **ux(ui-dashboard-support)** [#545] - 5 sites `except (AttributeError, OSError): pass` sans `logger.debug` -> insights muets impossibles a diagnostiquer.
