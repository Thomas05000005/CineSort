## Findings par categorie

### Categorie 3 — Logique metier (3 findings, 3 PRs)

#### 1. fake_4k sur profondeur de bits non mesuree — BUG (3) — PR #816

`detect_cross_verdicts` (composite_score.py:186) testait `effective_bits_mean < 8.0` pour flagger un faux 4K (upscale 8 bits vendu comme HDR 10 bits). Or `effective_bits_mean` vaut **0.0 par defaut** quand la profondeur de bits n'a pas pu etre mesuree : `_apply_pixel_aggregates` (video_analysis.py) ne renseigne la valeur que `if agg["bits"]`, et la source de bits est **independante** de celle du blur (deux agregats distincts).

**Consequence** : un fichier legitime dont la profondeur de bits n'a pas ete extraite (0.0) declenchait un faux verdict `fake_4k`. Corrige en borne basse stricte `0.0 < bits < 8.0` : le sentinel non-mesure est desormais ignore.

Test ajoute : `test_fake_4k_unmeasured_bits_no_verdict` (`effective_bits_mean=0.0` ne doit PAS declencher fake_4k).

#### 2. Annee TV perdue en arborescence plate — QUALITY (2) — PR #817 (Closes #814)

`parse_tv_info` (tv_helpers.py:120) extrait **saison** et **episode** du nom de fichier, mais ne cherchait l'**annee** que dans le nom de dossier. En arborescence plate — frequente sur des telechargements — l'annee presente uniquement dans le fichier etait perdue (asymetrie avec saison/episode).

Exemple : `Downloads/Breaking.Bad.2008.S01E01.mkv` -> `year=None` alors que `season=1, episode=1` sont bien extraits.

Corrige par une liste ordonnee de sources d'annee (dossier serie prioritaire, puis `video_name`), premiere correspondance `(19|20)\d{2}` retenue. La priorite au dossier est preservee (non-regression `test_year_extracted_from_folder`).

Test ajoute : `test_year_extracted_from_filename_flat_layout`.

#### 3. Garde mort sur `state_dir` vide — QUALITY (2) — PR #818 (Closes #815)

`_write_crash_for_run` (job_runner.py:90) construit `state_dir = Path(str(row.get("state_dir") or ""))` puis teste `if not state_dir: return`. Un objet `Path` est **toujours** truthy, et `Path("")` vaut `Path(".")` : le garde ne se declenchait jamais. Un run sans `state_dir` ecrivait alors `./runs/tri_films_<id>/crash.txt` **dans le repertoire courant du process** au lieu de sortir proprement.

Corrige en testant la chaine brute (`.strip()`) avant de construire le `Path`.

Tests ajoutes : `test_crash_writer_skips_empty_state_dir` (aucun `runs/` cree dans le CWD) + `test_crash_writer_writes_file_for_valid_state_dir`.
